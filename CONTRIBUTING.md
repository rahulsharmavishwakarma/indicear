# Contributing

IndicEAR is a research release. Bug reports, reproductions on other hardware and evaluation results
are welcome as issues; please open an issue before a large pull request.

## Development setup

The project uses [uv](https://docs.astral.sh/uv/). Training and tests run on free-threaded
CPython 3.14t (`.python-version`); uv installs it.

```bash
uv sync --locked
uv run --locked pytest -q        # CPU test suite, no network or GPU needed
uv run --locked ruff check .
```

Change dependencies with `uv add` / `uv remove` so `pyproject.toml` and `uv.lock` stay in sync.
`notebooks/*.ipynb` are generated by `notebooks/make_notebooks.py`, and `requirements-colab.txt`
by `uv export` (the command is in its header); edit the sources and regenerate rather than editing
those files. CI checks all of this on every pull request.

## Pull requests

- Keep a pull request to one change, with tests for behaviour changes.
- Update the relevant page under `docs/` in the same pull request.
- Results you report should name the model package, data revision, hardware and command, as the
  files under `results/` do.
